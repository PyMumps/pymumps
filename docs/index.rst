PyMUMPS Documentation
=====================

PyMUMPS provides Python bindings for `MUMPS <https://mumps-solver.org/>`_,
a parallel sparse direct solver.

The package exposes both:

- low-level context classes mirroring MUMPS job-based workflows,
- high-level convenience helpers for sparse linear solves.
